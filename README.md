# StreamScout Downloader

Official update repository for StreamScout Downloader.

- Windows desktop application
- Updates are published through GitHub Releases
- The app checks the latest GitHub Release and can download, replace, and restart itself
- DRM circumvention is not supported

## Automatic update channel

Repository: `kjw19841218-star/StreamScoutDownloader`
